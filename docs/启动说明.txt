溯源 ImageTrace 1.0.0
=====================

把同事发来的图拖进窗口，找出它的 PSD / AI / CDR 源文件。
纯本地运行，不上传任何文件。


一、先确认你的电脑能用
----------------------

需要 WebView2 运行时（用来显示界面）。

  Windows 11        自带，不用管
  Windows 10 1803+  多数自带。如果双击没反应，去微软官网装：
                    https://developer.microsoft.com/microsoft-edge/webview2/

其余依赖（Python、图像库、模型）全部已打包在 _internal\ 里，不用装。


二、第一次使用（四步）
----------------------

  1. 把整个文件夹解压到任意可写位置
     ✓ D:\软件\溯源\
     ✗ C:\Program Files\溯源\   （这里不可写，索引会存到用户目录）

  2. 双击 溯源.exe

  3. 点右上角齿轮 → 添加要索引的目录（比如 D:\workspace）

  4. 等索引建完。18,000 个文件约 20 分钟。
     建完之后日常查询是 100~300 毫秒。


三、四种搜索方式
----------------

  文件名     顶栏输入框直接打字            记得名字
  以图搜图   把图拖进窗口，或 Ctrl+V 粘贴   只有图，不知道叫什么
  图上文字   切到「图中文」模式输入          记得图上印的字
  画面内容   切到「画面」模式输入            只记得画面长什么样

后两种需要先建各自的索引：
  - 图上文字：点顶栏「文字索引」按钮，勾选范围后开始
  - 画面内容：切到「画面」模式，按提示建索引

两个都是分批跑的，随时可以暂停、下次接着做。


四、如果你下的是 lite 版
------------------------

lite 版不含中文 CLIP 模型（182MB），所以「画面」搜索不可用，
点进去会提示缺文件。其余功能完全一样。

要补上：下载 models-1.0.0.zip，把里面的 3 个文件解压到
        _internal\models\ 目录，重启程序即可。


五、你的数据存在哪
------------------

  data\              索引库和缩略图缓存（首次运行自动创建）
  data\window.json   窗口大小和位置

  - 所有数据只在本机，没有任何云同步
  - 索引库记录了你文件的绝对路径，别把 data\ 发给别人
  - 想重建索引：删掉 data\ 重启程序
  - 卸载：删掉整个文件夹即可


六、命令行（可选）
------------------

  溯源.exe --selftest     自检，结果写到 data\selftest.log
  溯源.exe --browser      用默认浏览器打开，不开独立窗口
  溯源.exe --port 8899    换端口（默认 8848）


七、出问题怎么办
----------------

  双击没反应          → 装 WebView2（见第一节）
  界面能开但很慢      → 检查索引记录数，可能在重建
  右键菜单看不到      → 重启资源管理器（任务管理器 → 重新启动）
  画面搜索提示缺文件  → 你下的是 lite 版，见第四节
