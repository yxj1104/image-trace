规则
  • 一套字体：系统 UI 字体栈，Windows 上是 Segoe UI + 微软雅黑，Mac 上是 SF + 苹方。不引入 Web Font，启动零等待。
  • 数字等宽：全局 font-feature-settings: "tnum" 1，匹配度 97% 和 8% 不会左右跳。
  • 只有两个字重：400 正文、600 标题。不用 500，避免小字号下发虚。
  • 行高：正文 1.55，标题 1.2。不为单行文字单独设行高。
  • 字距：标题 -.01em，大写标签 +.06em，其余 0。
